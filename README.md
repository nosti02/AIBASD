Booking system based on the example in the AI-Based Agile Software Development 2026 lecture.

Code and testcases were generated by GitHub Copilot.

Confirmed bookings and the waiting list are represented by json files.
The system offers protection against accidental double bookings.

Future updates could include features such as cancelation and promotion from the waiting list.

The testcases check for:

Correct bookings up to 10 places and working placing on the waiting list.
Bookings persist in memory (json file).
Double bookings are detected and handled as expected.
Tests correct output on both lists.

The pytest module is required to run the tests.
